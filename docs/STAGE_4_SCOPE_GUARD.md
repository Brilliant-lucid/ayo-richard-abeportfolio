# Stage 4 — Scope Guard

This file exists to prevent later documentation from accidentally turning future plans into current technical facts.

## Current technical facts

- Full-stack TanStack Start application.
- Supabase authentication, PostgreSQL persistence, and Storage.
- Username/path-based public portfolios.
- Authenticated `/admin/*` management surface.
- Server-function application layer.
- MCP endpoint with a limited registered tool set.

## Current transitional architecture

- Service-role Supabase access.
- Legacy/new project field compatibility.
- Project/Case Study consolidation.
- Contact/service-inquiry overlap.
- External Lovable integration dependencies.

## Future architecture

- Independent/owned backend infrastructure if migration proceeds.
- Subdomain-based portfolio architecture if adopted.
- Complete Career Profile engine.
- Complete Visual Template System.
- Expanded AI authoring.
- Expanded MCP capabilities.
- Professional verification infrastructure.

## Documentation rule

Use words such as **planned**, **proposed**, **future**, or **active development** for future systems. Use **implemented** only when repository evidence supports the claim and, for production-readiness claims, runtime verification has also passed.
