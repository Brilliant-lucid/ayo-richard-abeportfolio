# Stage 11G — Cost, Capacity & Scaling Validation

## Objective

Understand the operating cost and capacity profile before significant user growth.

## Cost components

Model at least:

- Hosting/runtime.
- Database.
- Storage.
- Bandwidth.
- Email.
- Artificial Intelligence (AI) usage.
- MCP/runtime usage.
- Monitoring/analytics.
- Domain and ancillary services.

## Growth scenarios

Model:

- 100 users.
- 1,000 users.
- 10,000 users.
- 100,000 users.

For each scenario estimate:

- Registered users.
- Monthly active users.
- Published portfolios.
- Storage per user.
- Public page views.
- Media bandwidth.
- Emails.
- AI requests.
- MCP requests.

## Unit economics

Calculate:

**Monthly infrastructure cost / monthly active users**

and where useful:

**Monthly infrastructure cost / published portfolio**

## Guardrails

Define practical limits for:

- Upload size.
- Storage quota.
- Project count.
- Content volume.
- Contact submissions.
- Email frequency.
- AI requests.
- MCP requests.

## Scaling triggers

Define when to review or change architecture, such as:

- Database utilization.
- Storage growth.
- Query latency.
- Bandwidth cost.
- Runtime limits.
- Error rates.

## Completion evidence

Record assumptions, provider pricing snapshot, calculations, limits, capacity risks, and next review threshold.
